# Sécurité

DDCBot manipule des données de serveurs Discord (modération, économie, logs). Les jetons et données sensibles ne doivent jamais être commités.

## Signaler une vulnérabilité

- Ne publiez **pas** la vulnérabilité dans une issue publique.
- Utilisez la [signalisation privée de vulnérabilité GitHub](https://github.com/Estemobs/ddcbot/security/advisories) (Security tab → Report a vulnerability).
- Pour les problèmes sensibles, contactez directement le mainteneur via Discord.

Vous recevrez un accusé de réception sous quelques jours. Merci de ne pas exploiter la faille et de donner un délai raisonnable avant toute divulgation.
